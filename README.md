# 24XRAVEN SMS Bot

بوت تليجرام احترافي لإدارة أرقام SMS ومراقبة OTPs من iVasms، مع لوحة تحكم ويب.

## المميزات

- 🤖 بوت تليجرام تفاعلي (توزيع أرقام، استقبال OTPs)
- 👁️ مراقبة تلقائية لـ iVasms وإرسال OTPs
- 🎛️ لوحة تحكم ويب للمراقبة والتحكم
- 🔐 نظام اشتراك إجباري
- 🚫 حظر/فك حظر المستخدمين
- 📊 إحصائيات مفصلة
- 💾 قاعدة بيانات SQLite/PostgreSQL
- 🔄 منع تكرار OTPs

## المتطلبات

- Python 3.10+
- حساب iVasms
- بوت تليجرام (من @BotFather)
